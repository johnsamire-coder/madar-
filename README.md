# مدار — منصة إدارة السوشيال ميديا (MVP)

المرحلة الأولى خلصت: حساب آمن + مساحة عمل + لوحة تحكم.

## التشغيل من الصفر

1. ثبّت الحزم:
   ```bash
   npm install
   ```
2. شغّل قاعدة البيانات المحلية المجانية (بتتحفظ داخل المشروع في `.local/postgres`):
   ```bash
   npm run db:local
   ```
3. في نافذة تانية، أنشئ الجداول (لأول مرة بس):
   ```bash
   npm run db:setup
   ```
4. شغّل الموقع:
   ```bash
   npm run dev
   ```
5. افتح `http://localhost:3000` وسجّل حسابك.

### حساب جاهز للتجربة
سيبنا لك حسابًا تجريبيًا على جهازك:
- البريد: `live-demo@example.test`
- كلمة المرور: `Live-Demo-Password-2026!`

### تشغيل اختبارات المتصفح
اختبارات المتصفح بتستخدم `http://127.0.0.1:3000`، فلو هتشغّلها شغّل السيرفر كذا:
```bash
npm run dev -- --hostname 127.0.0.1
```
## الأوامر

- `npm run db:local` — تشغيل PostgreSQL محلية على المنفذ 54329 بدون أي اشتراك.
- `npm run db:setup` — تنفيذ هيكلة الجداول على قاعدة البيانات الحالية.
- `npm run test:auth` — اختبارات التسجيل والدخول وتشفير كلمة المرور.
- `npm run test:e2e` — اختبار المتصفح الحقيقي (يحتاج `npm run db:local` و`npm run dev` شغالين).
- `npm run build` — بناء نسخة الإنتاج والتأكد إن مفيش أخطاء.

## اللي اتعمل في المرحلة الأولى

- تسجيل حساب جديد بالاسم + اسم مساحة العمل + إيميل + كلمة مرور (١٢ حرف على الأقل).
- كلمة المرور بتتخزين مشفرة (bcrypt) — محدش يقدر يقرأها حتى من قاعدة البيانات.
- جلسة دخول بملف تعريف آمن (HttpOnly) صالحة ٧ أيام، بتتحفظ في قاعدة البيانات كقيمة مشفرة.
- حد لمحاولات الدخول الخاطئة لمنع تخمين كلمات المرور.
- لوحة تحكم بالعربي (RTL): شريط جانبي، هيدر، بيانات حقيقية فقط (مفيش أرقام تجريبية).
- الصفحات المؤمّنة: `/dashboard` و`/dashboard/settings`؛ أي زائر بيتحول لصفحة الدخول.
- حدود واضحة للمراحل الجاية: ربط فيسبوك/إنستجرام/تيك توك (مرحلة ٢)، النشر والجدولة (مرحلة ٣)، التحليلات (مرحلة ٤).

## الإنتاج

قبل النشر الفعلي: وفّر PostgreSQL خارجية، وارفع `DATABASE_URL` و`APP_URL`، وفعّل `TRUST_PROXY=true` خلف proxy موثوق بس، وغيّر مدة/سياسة الجلسات حسب الحاجة.
